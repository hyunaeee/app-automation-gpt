# Atelier · 모바일 디자인 스튜디오

먼저 만든 `design/reference-v1.png`의 세 화면을 기준으로 구현한 모바일 앱입니다. 소스 ZIP에서는 `design/`을 루트에 제공하며, 개발 저장소에서는 `app/`의 형제 디렉터리에 있습니다. Studio, 디자인 상세, 견적, Library, Materials 화면을 포함합니다.

## 실행

Node.js 22 이상에서 `npm start`를 실행합니다. `PORT=3005`처럼 환경변수로 미리보기 포트를 정할 수 있습니다. Android APK에서는 서버 없이 public 폴더의 화면을 오프라인으로 실행합니다.

## 실제 동작

- 새 디자인 설명에서 가방·상의, 명시된 cm 치수와 지원 컬러를 로컬 규칙으로 읽습니다.
- 가로·세로·깊이·시접 등을 직접 조절하면 SVG 개념도와 견적을 다시 계산합니다.
- 원단 폭, 손실률, 수량, 원단·안감·부자재 단가와 공임·개발비를 수정합니다.
- 디자인을 기기에 저장·수정·삭제하고 다시 열 수 있습니다.
- 제작 업체 검색어와 실제 입력을 담은 문의 브리프를 제공합니다. 복사 권한이 없는 기기에서는 선택 가능한 텍스트를 직접 복사할 수 있습니다.

## 계산과 이미지의 범위

이미지는 미리 생성한 정적 AI 컨셉이며 치수·색상 변경으로 다시 생성되지 않습니다. 치수 개념도는 사용자 입력값을 표시하며 실측이나 봉제용 실물 패턴이 아닙니다.

재료는 시접을 더한 사각형 부품을 원단의 결 방향을 유지해 행에 배치합니다. 손실률을 길이에 추가하고 0.1m 단위로 올림합니다. 상의는 몸판·소매 바운딩 박스 추정이며 곡선·넥밴드·신축률은 반영하지 않습니다. 실제 사양과 제작 가능 여부는 패턴사·제작처 확인이 필요합니다.

단가와 공임은 가정값이며 세금·배송비를 제외합니다. 통화 선택은 환율 변환을 하지 않습니다. 제휴 업체나 자동 문의 전송 기능은 포함하지 않습니다.

저장은 브라우저 또는 Android WebView의 localStorage를 사용합니다. 기기 간 동기화가 없으며 앱 삭제·데이터 초기화 시 기록도 사라집니다. 사진, CSS, JavaScript가 모두 포함되어 외부 CDN이나 네트워크 요청 없이 작동합니다.
